# Neovim config

## Editing

- [nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter) for syntax highlighting
- [blink.cmp](https://github.com/saghen/blink.cmp) and [LuaSnip](https://github.com/L3MON4D3/LuaSnip) for completion
- [nvim-lspconfig](https://github.com/neovim/nvim-lspconfig) with [mason.nvim](https://github.com/mason-org/mason.nvim) for language servers (`clangd`, `lua_ls`)
- [conform.nvim](https://github.com/stevearc/conform.nvim) formats Lua with StyLua on save
- [nvim-lint](https://github.com/mfussenegger/nvim-lint) and [ft_nvim](https://github.com/vinicius507/ft_nvim) for C (42 header and norminette)
- [guess-indent.nvim](https://github.com/NMAC427/guess-indent.nvim) detects indentation from the buffer
- [mini.nvim](https://github.com/echasnovski/mini.nvim) for textobjects, surround, and the statusline

## Navigation

- [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) finds files, text, buffers, and help
- [neo-tree.nvim](https://github.com/nvim-neo-tree/neo-tree.nvim) is the file tree (`\` reveals the current file)
- [which-key.nvim](https://github.com/folke/which-key.nvim) shows available keymaps
- [vim-tmux-navigator](https://github.com/christoomey/vim-tmux-navigator) moves between Neovim and tmux panes with `Ctrl-h/j/k/l`

## Git

- [gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim) shows and stages hunks
- [diffview.nvim](https://github.com/sindrets/diffview.nvim) opens a full diff and file history

## Notes and appearance

- [tokyonight.nvim](https://github.com/folke/tokyonight.nvim) is the colorscheme
- [todo-comments.nvim](https://github.com/folke/todo-comments.nvim) highlights `TODO` and `FIXME`
- [render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim), [mkdnflow.nvim](https://github.com/jakewvincent/mkdnflow.nvim), and [zk-nvim](https://github.com/zk-org/zk-nvim) are for Markdown notes

## Other

- [vim-be-good](https://github.com/ThePrimeagen/vim-be-good) is a Vim practice game (`:VimBeGood`)
